## 法国原生IP有哪几种，价格差在哪

“原生”“住宅”“家宽”“ISP 代理”这四个词经常被混着用，实际对应四种不同的东西，价钱和用途都不一样。

**机房原生 IP**：IP 归属国是法国，但 ASN 落在数据中心。OuiHeberg 的巴黎 VPS 就是这一类，$8.11/月给 2 核 / 4GB DDR4 ECC / 45GB NVMe，1~10Gbps 端口、不限流量，含 1 个 IPv4 加 IPv6 双栈。它的 IP 归属和机房都在巴黎，纯净度不差，但属性上仍是机房地址。

**住宅 IP**：判断依据是 ISP 归属，地址登记在宽带运营商名下，而不是数据中心。法国本土的住宅宽带品牌是 Orange、SFR、Bouygues Telecom、Free 这几家。

**原生家宽**：归属国对、ISP 也是运营商，两个条件同时成立。WePC 法国节点在产品页写的是“法国原生家宽 IPv4 x1”，属于这一类。

**静态 ISP 代理**：ASN 显示为法国运营商，但地址开在服务器上。ProxyJam 在自己的法国页面上写得很直白：这类地址不属于某个家庭的路由器，它由服务器基础设施下发，只是查询结果看起来是运营商网络。它按 IP 计费、不按流量，$5.38/IP/月，整期地址不变，法国可选运营商列表里是 Lietpark Communications、Lumina Broadband、NTT、Orange、Sc Technological Sr，没有 SFR、Bouygues、Free。

## 买回来怎么验证它到底是不是法国住宅

这一步比看商家宣传有用。法国的 IP 地址空间由 RIPE NCC 分配，RIPE 数据库记录某段法国地址归谁持有、哪个网络在宣告它。任何第三方查询工具读的都是这份记录。ARCEP 是法国的电子通信监管机构，管牌照和运营商义务，不发 IP，查不到地址归属时别去那里找。

操作上分三步：

1. 拿 VPS 的 IPv4 去 RIPE 数据库查持有者与宣告网络，看归属国是不是法国。
2. 查 ASN。如果落在 Orange、SFR、Bouygues Telecom、Free 这类法国住宅宽带运营商，住宅属性基本成立；落在数据中心 ASN，就是机房 IP 换了个法国归属。注意运营商列表和住宅不是等号，ProxyJam 自己就写明它的法国 ISP 代理开在服务器上。
3. 打开一个法国站点看它给你什么版本。法国站点按 IP 归属国判断市场，不按浏览器语言，法语同时是比利时、瑞士、加拿大的官方语言。`.fr` 域名由 AFNIC 管理，法国站给本地访客的价格、库存、配送选项和给外国访客的不一样。

做法国市场投放的人还该知道 Toubon 法案：在法国境内展示的广告必须使用法语，其他语言只能作为法语版本的并列版本。用法国地址加载落地页，如果只出英文创意，这个投放设置值得回头检查。
